### Smoke-test record (2026-11-04, the shipping pair)

Game runtime 1.16.244.0; session 14:51–14:57, Starfield restarted, both front
ends used in one run.

- Both DLLs report `1.0.0.0` and load: ImGui as "standalone overlay (no game
  menu host)", OSF as "OSF UI view front end". No duplicate-plugin warning.
- `SFShopExplorer.log` 5,557 lines / 870 KB, `DevilzShopOSF.log` 2,292 lines /
  415 KB, **0 `[E]` in either**, both shut down cleanly (audio worker stopped,
  WASAPI resources released).
- **Noise change confirmed:** the mesh vert/index mismatch logs three WARNs per
  session (2 index + 1 vert in each log) where the previous session had 1,292.
- **Mask split confirmed:** the one refused mask this session logged at INFO
  with its reason (`degenerate <8x8 mask fmt=80`); absent derived masks stayed at
  DEBUG and are absent at `level=info`, as designed.
- Standalone: 243 Clone3D previews and 46 typed-item NIF previews, catalog of
  6,460 forms, restored sort, four backdrops, six music tracks.
- OSF: view opened and closed three times from Mod Settings, four preview drags,
  backdrop diagnostics and the custom soundtrack active.
- **Not exercised:** an AMMO crate preview, so the absent-placeholder fallback
  did not fire. Basket, purchase and theme switches leave no log line, so the
  logs cannot confirm them.
- Content WARNs, all third-party gaps the code already degrades gracefully on:
